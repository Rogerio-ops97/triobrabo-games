# FreeDrop

PWA para descobrir jogos temporariamente grátis nas principais lojas.

## Rodar localmente

1. Copie `.env.example` para `.env.local` e preencha as variáveis.
2. Execute `pnpm install` e `pnpm dev`.
3. Abra `http://localhost:3000`.

Sem variáveis Supabase, a interface usa um catálogo demonstrativo. O esquema está em `supabase/migrations` e o plano completo em `docs/PLANO.md`.
